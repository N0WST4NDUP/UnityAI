# REWARDS.md

직군별 보상 함수 명세. 수식은 Phase 2 구현의 기준이 된다.

## 공통 (모든 UnitAgent)

| 항목 | 값 | 설명 |
|------|----|----|
| 승리 보너스 | `+1.0` | 판 종료 시 승리 팀 유닛 전원 |
| 패배 패널티 | `-1.0` | 판 종료 시 패배 팀 유닛 전원 |
| 생존 보너스 | `+0.001 / step` | 과도한 자살 행동 방지 |
| 사망 패널티 | `-0.3` | 조기 사망 억제 |
| 팀킬 방지 | `-0.5` | 아군 피해 시 |

## 탱커

```
R_tank = R_common
       + α_aggro * (유인한 적 공격 횟수)
       + α_tank  * (본인이 받은 피해 중 구조물 대신 막은 비율)
       - β_dist  * (아군 후열과의 거리 초과 패널티)
```

| 계수 | 초기값 | 비고 |
|------|--------|------|
| α_aggro | 0.02 | 어그로 유인 |
| α_tank | 0.05 | 탱킹 피해량 |
| β_dist | 0.01 | 전열 이탈 억제 |

## 딜러 / 암살자

```
R_dealer = R_common
         + α_kill   * (핵심 유닛 처치 수; 적 딜러/마법사 가중치↑)
         + α_struct * (구조물 파괴 피해량)
         - β_expose * (무방비 피격 수)
```

| 계수 | 초기값 |
|------|--------|
| α_kill | 0.1 |
| α_struct | 0.03 |
| β_expose | 0.02 |

## 마법사

```
R_mage = R_common
       + α_hit    * (스킬 적중 유닛 수)
       + α_range  * (스킬 총 범위 피해량)
       - β_ally   * (아군에게 입힌 범위 피해)
```

| 계수 | 초기값 |
|------|--------|
| α_hit | 0.04 |
| α_range | 0.02 |
| β_ally | 0.1 |

## Commander

```
R_cmd = R_common (팀 전체 승패)
      + γ_synergy * (명령 ↔ 시너지 일치도)
      + γ_dramatic * (극적 연출 지표: 역전/전멸 회피)
      - δ_stale * (교착 상태 지속 패널티)
```

| 계수 | 초기값 |
|------|--------|
| γ_synergy | 0.05 |
| γ_dramatic | 0.03 |
| δ_stale | 0.01 |

## 시너지 Reward Shaping

| 시너지 | 변경 |
|--------|------|
| 공격적 | `β_dist` ×0.5, 전진 step당 `+0.002` 추가 |
| 수비적 | `α_aggro` ×1.5, 포지션 유지 `+0.002` |

## 주의사항
- 모든 계수는 초기값이며 Phase 2 Tensorboard 분석 후 튜닝.
- 사망 패널티와 생존 보너스의 합이 0 이하가 되어야 무의미한 배회를 억제한다.
- Commander의 δ_stale은 포트폴리오용 극적 연출 목표(D)에 직결 → Phase 5에서 재튜닝.

# REWARDS.md

직군별 보상 함수 명세. 수식은 Phase 2~3 구현의 기준이 된다.

> **2026-04-20 Feudal HRL 재설계 반영** — 유닛/커맨더 보상을 완전 분리. 유닛에 승/패 보상 금지. 자세한 배경은 [CLAUDE.md](../CLAUDE.md) "AI 아키텍처" 참조.

## 0. 설계 원칙 (독립성 마지노선)

| 원칙 | 설명 |
|---|---|
| **유닛 승/패 보상 금지** | 유닛 보상에 팀 승리/패배 신호를 **절대 포함하지 않는다**. 포함 시 커맨더 Policy와 종속됨. |
| **유닛 = 수행도 중심** | 유닛 보상은 "커맨더 명령을 얼마나 잘 수행했나"를 중심으로 구성. |
| **커맨더 = 팀 성과 중심** | 커맨더 보상은 승/패 + 최소 dense 지표. 유닛 행동에 대한 직접 보상 없음. |
| **보상 누수 방지** | 둘 사이 공통 항목이 있을 경우 어느 쪽에 주는지 명시. |

## 1. Unit Agent 보상 (수행도 80% + Micro 20%)

유닛은 자기 분대의 `CurrentCommand`에 따라 **매 step 평가**된다.

### 1-1. 수행도 (Compliance) — 총 가중치 0.8

| 항목 | 값 | 조건 | 비고 |
|---|---|---|---|
| 타겟 매치 | `+0.02 / step` | 공격 대상이 명령 `priority_filter`와 일치할 때 | filter가 "전체 무시"면 0 |
| 영역 근접 | `+0.01 / step` | 명령 `target_position` 반경 내에 있을 때 | 반경은 분대당 설정 |
| 영역 수렴 | `+0.005 * Δd` | step당 target_position에 가까워진 거리 차분 | 음수 시 패널티 |
| 구조물 처리 매치 | `+0.03` | 명령이 "부수기"고 구조물 공격 성공 시 | 이벤트 기반, step보상 아님 |
| 구조물 회피 매치 | `+0.01 / step` | 명령이 "우회"인데 구조물과 일정 거리 유지 | |
| 명령 위반 | `-0.05 / step` | 우선순위 무시, 지정 영역 이탈 시 | 강한 패널티 |

### 1-2. Micro 품질 — 총 가중치 0.2

| 항목 | 값 | 비고 |
|---|---|---|
| 공격 성공 | `+0.005` | 쿨타임마다 피해 성공 시 (타겟 매치 여부 무관) |
| 피격 회피 | `+0.002 / step` | HP 감소 없을 때 (탱커는 미적용) |
| 스킬 적중 수 | `+0.01 * N` | 마법사 AoE (아군 제외) |
| 사망 | `-0.1` | **소규모 페널티만**. 생존을 명령 수행보다 우선시하지 않기 위해 |
| 아군 오폭 | `-0.1` | 마법사 AoE가 아군에 닿음 |

### 1-3. 직군별 차별 계수

수행도·Micro 계수를 직군별로 미세 조정.

| 직군 | 특이 계수 |
|---|---|
| 탱커 | `피격 회피` 계수 ×0 (어그로 유인이 목적), `영역 근접` 계수 ×1.5 |
| 딜러 | `공격 성공` 계수 ×1.5, `타겟 매치` 계수 ×1.3 |
| 마법사 | `스킬 적중 수` 핵심, `아군 오폭` ×1.5 |

### 1-4. 절대 금지

- ❌ 팀 승리 보너스
- ❌ 팀 패배 패널티
- ❌ 적 유닛 총 처치 수 (명령 priority와 무관하므로 commander 학습과 섞임)

## 2. Commander Agent 보상 (Sparse + 최소 Dense)

커맨더는 **2초 tick 기준** 또는 **에피소드 경계**에서 보상을 받는다.

### 2-1. Sparse (에피소드 종료)

| 항목 | 값 | 비고 |
|---|---|---|
| 승리 | `+1.0` | 적 팀 전멸 또는 시간 초과 시 우세 |
| 패배 | `-1.0` | |
| 무승부 | `-0.1` | 교착 억제 |

### 2-2. 최소 Dense (에피소드 중)

| 항목 | 값 | 주기 | 비고 |
|---|---|---|---|
| 아군 유닛 손실 | `-0.05 / 유닛` | 사건 발생 시 | |
| 적 유닛 처치 | `+0.05 / 유닛` | 사건 발생 시 | |
| 적 구조물 파괴 | `+0.1 / 구조물` | 사건 발생 시 | |
| 아군 구조물 상실 | `-0.1 / 구조물` | 사건 발생 시 | |
| 교착 상태 | `-0.01 / tick` | 2초 tick마다 교전이 N 스텝 이상 없으면 | 극적 연출 |

### 2-3. 금지

- ❌ 특정 유닛의 micro 성공 (타겟 적중 등) — 유닛 policy 책임
- ❌ 명령 수행도 — 유닛이 명령 잘 따르는 것은 유닛 학습 결과일 뿐

## 3. 시너지 Reward Shaping

시너지는 **유닛 보상의 계수**만 조정한다 (커맨더 보상은 건드리지 않음).

| 시너지 | 변경 대상 | 조정 |
|--------|---------|------|
| 공격적 | 딜러 `공격 성공` | ×1.5 |
| 공격적 | 전체 `영역 수렴` | ×1.3 (전진 보상) |
| 수비적 | 탱커 `영역 근접` | ×1.5 |
| 수비적 | 전체 `피격 회피` | ×1.5 |
| 은신 | 딜러 `명령 위반` (후방 이동) 완화 | ×0.5 |

## 4. 학습 스테이지별 보상 적용

**Stage 1 (Scripted 커맨더 + Scripted 유닛)**: 보상 미적용, 파이프라인 검증용.

**Stage 2 (Scripted 커맨더 + RL 유닛)**:
- 유닛 보상 §1 전면 적용
- 커맨더 보상 미적용 (학습 안 함)

**Stage 3 (RL 커맨더 + Frozen 유닛)**:
- 커맨더 보상 §2 전면 적용
- 유닛 보상 미적용 (정책 freeze)

**Stage 4 (선택, Phase 5 이후)** — Alternating fine-tune:
- 교대로 freeze/학습. 유닛 보상에 **승/패 신호 여전히 금지**.

---

## 5. 튜닝 및 주의사항

- 모든 계수는 **초기값**. Phase 2~3 Tensorboard 분석 후 조정.
- `사망` 패널티를 너무 크게 하면 유닛이 명령을 회피 → 독립성 깨짐. `-0.1` 이하 권장.
- `영역 수렴` 보상은 **거리 차분**(Δd) 기반. 단순 거리 기반은 왕복 exploit 유발.
- 커맨더 보상은 tick 단위로 너무 자주 주지 않기 (전략 판단은 느린 시그널이 맞음).
- 시너지 조정은 `docs/ARCHITECTURE.md`의 `SynergyFlags` 컴포넌트 경유.
